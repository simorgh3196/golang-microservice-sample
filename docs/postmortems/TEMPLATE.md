# PM-NNN: （障害を一文で。「X により Y が起きた」の形）

- **Date**: YYYY-MM-DD
- **関連 Step**: Step N
- **重大度**: Sev1（全停止）| Sev2（主要機能の劣化）| Sev3（限定的な影響）
- **影響範囲**: どのサービス・どのテナント・どの操作に影響したか

## 概要（3 行以内）

何が起きて、何が原因で、どう直したか。

## タイムライン

| 00:05 | 仮説 1 | |
| 00:10 | 根本原因を特定 | |

## 検知

- どうやって気づいたか（アラート / ログ / ユーザー報告 / 気づけなかった）。
- 本番なら何分で気づけたか。気づくために足りなかったものは何か。

## 根本原因（Root Cause）

「なぜ」を 5 回繰り返す。最後に残るのは「仕組み」であって「人」ではない。

1. なぜ症状が出たか →
2. なぜそれが起きたか →
3. なぜ →
4. なぜ →
5. なぜ →

## 寄与要因（Contributing Factors）

根本原因ではないが、被害を大きくした・検知を遅らせたもの。

## 教訓（設計原則に昇格するもの）

この障害から得た、他の場面にも適用できる一般的な原則。Step 16 で `docs/principles.md` に集約する。
